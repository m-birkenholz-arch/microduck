# Microduck GPT-Live

Schone eerste integratie met `gpt-live-1`.

Eerste stap: GPT-Live 1, WebRTC microfoon/audio, korte Nederlandse antwoorden en Marin-stem. Geen code uit eerdere Realtime/simulator-experimenten is overgenomen.

## Windows-test

1. Installeer Node.js 20 of nieuwer.
2. Open PowerShell in deze map.
3. Voer `./start.ps1` uit.
4. Vul je OpenAI API-key in.
5. Open `http://127.0.0.1:8787` in Chrome of Edge.
6. Klik **Start gesprek** en geef microfoontoegang.

De API-key blijft in het lokale Node-proces en wordt niet naar de browser gestuurd.
